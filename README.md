Ovaj projekt predstavlja web-aplikaciju za upravljanje skladištem robe i materijala, izrađenu pomoću ASP.NET Core MVC tehnologije i Entity Framework Core-a. Aplikacija omogućuje evidenciju materijala, unos robe kroz primke, izdavanje robe kroz međuskladišnice, praćenje skladišnih transakcija te generiranje PDF dokumenata za radne naloge i izvještaje.

Sustav uključuje autentikaciju korisnika, hashiranje lozinki te autorizaciju na temelju korisničkih uloga: zaposlenik, voditelj i administrator. Administrator može upravljati korisnicima i njihovim ulogama, dok voditelj ima pristup naprednim pregledima, izvještajima i statistici skladišnog poslovanja. Aplikacija dodatno podržava generiranje i skeniranje QR/barkod oznaka za materijale, čime se olakšava pretraga i identifikacija robe u skladištu.

Za pohranu podataka koristi se SQL Server baza podataka, a komunikacija s bazom ostvarena je pomoću Entity Framework Core-a. Projekt sadrži i dashboard za pregled ključnih informacija kao što su ukupne transakcije, materijali s niskom zalihom, najčešće korišteni materijali i aktivnost korisnika.
